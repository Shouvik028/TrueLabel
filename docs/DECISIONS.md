| 19 | 2026-11-01 | Upgrade from Expo SDK 54 to **SDK 58** (React Native 0.88, React 19.3, TypeScript 6, Node ≥ 22.13). Supersedes #2. Upgrade done one SDK at a time (55, 56, 57, 58) with `npx expo install expo@^N --fix`, running typecheck, lint, tests, `expo-doctor` and `expo export --platform ios` at each step; each green step was a WIP commit. Each in-place upgrade left duplicate native packages in `node_modules`, fixed by deleting `node_modules` and `package-lock.json` and reinstalling. Root, `packages/core` and `apps/mobile` all resolve TypeScript 6.0.3 | The Expo Go on the user's iPhone was updated and now supports only SDK 58, so an SDK 54 app no longer opens.
